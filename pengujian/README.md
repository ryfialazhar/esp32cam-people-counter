# Folder Pengujian

| File | Fungsi |
|---|---|
| `lembar_akurasi.csv` | Templat lembar uji akurasi. Salin ke `data/akurasi.csv` sebelum mengisi |
| `catat_serial.py` | Merekam log Serial ESP32 ke `data/` (butuh `pyserial`) |
| `analisis.py` | Mengolah data menjadi tabel dan grafik di `hasil/` (butuh `matplotlib`) |
| `contoh/` | Data **contoh rekaan** untuk mencoba skrip, bukan hasil pengujian sebenarnya |

Prosedur lengkap ada di [docs/06-rencana-pengujian.md](../docs/06-rencana-pengujian.md).
